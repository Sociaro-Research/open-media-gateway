# Support

Media Gateway is currently an early-preview community project and has no paid or
guaranteed support channel.

- Read the [README](README.md) and [configuration guide](docs/configuration.md) first.
- Use a GitHub issue for reproducible bugs and feature requests. Include the
  Gateway version or commit, operating system, Docker/Go version, relevant
  redacted logs, and reproduction steps.
- Use GitHub Discussions for usage questions once Discussions are enabled.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never report those in a
  public issue.

Do not post API keys, access keys, authorization headers, `.env` contents,
provider result URLs, customer prompts, or generated media in support requests.
