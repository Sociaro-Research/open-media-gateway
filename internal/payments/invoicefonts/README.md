# Invoice fonts

Liberation Sans Regular and Bold **1.07.4** are embedded for invoice text. The
files are unmodified. Their version and bytes were verified against the pinned
Mozilla PDF.js copies recorded in `provenance.json`; this records a verified byte
match, not an undocumented original acquisition event.

The matching upstream notice identifies these fonts as **GNU GPL v2 with the
Liberation font exception**. `LICENSE` is an unmodified copy of that release's
notice and GPL text from the pinned PDF.js revision. Liberation 2.0 and later use
the SIL Open Font License; that newer notice does not describe these 1.07.4 files.
This font-specific statement does not assign a license to the whole application.

Keep the original font notice with source and binary distributions. The backend
image collector includes it as `LiberationSans-LICENSE`. When changing a font,
review its version, original notice and provenance together. The current tree
contains the TTFs and matching notices, not an upstream font-source/build archive;
source-delivery packaging for a binary release remains a separate release gate.

The compatible sans-serif files provide Unicode Latin, Greek and Cyrillic glyph
coverage. No provider logo or font bytes were modified by the notice correction.
